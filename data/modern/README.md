# data/modern

Game data (JSON) for the Modern World mode. Every file records its source and the date it was checked in its `meta` block (GDD section 14).

The map files (`provinces.json`, `countries.json`, `cities.json`, `sea-routes.json`, `map/`) are generated by `npm run data:build`. Do not edit them by hand; change `tools/map/config.json` and rebuild. See `tools/README.md`.
